# 写作沙盒 · 昔涟

✍️ **AstrBot 委托式独立写作沙盒** —— 对昔涟说一句「写一段……」，她就在后台为你分节写作，自动保存成 txt，写完告诉你。你只负责描述「想要什么效果」，剩下的交给她。

不需要记任何指令前缀，用自然语言说话就行。

## ✨ 特色

- **自然语言吩咐**：不用学命令，「写一段她推门进来，雨还没干」就是全部操作方式
- **独立沙盒**：写作上下文和主聊天完全隔离，聊着天写作互不打扰
- **后台分节生成**：长文自动拆成每节约 4000 字的小节逐节后台写，你可以先干别的
- **风格卡学习**：丢几篇素材进去，提炼成「风格卡」，以后都按这个味道写
- **长篇连载工作区**：大纲、设定书、章节摘要自动维护，写不跑偏
- **产出自动落盘**：每段文字保存为 txt，回复里给摘要和路径，随时可取

## 🚀 快速开始

1. 把插件文件夹放进 AstrBot 的 `data/plugins/`，重启或热加载
2. 直接对昔涟说：

```
写一段她推门进来，雨还没干
```

她会在后台生成文字、保存成 txt，然后告诉你写好了。

## 🎮 怎么用（说人话就行）

| 你只要说 | 沙盒会做什么 |
| --- | --- |
| 写一段…… / 续写 / 改写上一段 | 按当前风格卡 + 约束生成文字，落盘 txt，写完推送 |
| 这段太短 / 太长 / 换第一人称 / 节奏快一点 | 调整对应约束项，下次生成立即生效 |
| 这段好，收藏 | 存为高权重样本，以后风格学习优先参考 |
| 学一下这些素材的风格 | 从素材库提炼风格卡，之后都按这个味道写 |
| 写《XX》第 3 章 | 进入长篇模式，自动维护章节摘要和设定书 |
| 给《XX》定个大纲 | 规划全局脉络 + 分章节点，写作时自动注入 |
| 给配角也设个卡 | 生成统一格式人设卡，写正文时按出场角色自动注入 |
| 看看沙盒现在是什么设置 | 查看当前风格卡与约束 |
| 写到哪了 / 后台好了吗 | 查看后台写作进度 |
| 清空沙盒 | 重置沙盒历史（可连约束、风格卡一起清） |

## 🧠 它怎么工作（了解一下更好用）

- 每次生成 = 系统提示词 + 风格卡 + 约束 + 沙盒历史 + 你这次的指令
- 沙盒历史独立保存，写长文时不会和日常聊天串味
- 长文自动分节后台生成，中途随时可问进度
- 产出保存在 `outputs/` 目录，按时间命名

## 🎨 风格卡：教「怎么写」，不教「写什么」

风格学习只捕获**笔法维度**，跟剧情和人设彻底解耦：

- 句式结构、词汇偏好、描写侧重与密度
- 人称与视角、节奏快慢、感官侧重
- 尺度与露骨度、比喻方式

**不收录**：语气、题材、具体意象词。这样一张风格卡可以跨题材复用，不会一写某角色就自动带上某篇文的标签。

- 素材放 `library/`（txt / md），收藏的样本自动优先
- 多张风格卡可以**组合**：设一张底卡，再按维度指定来源（比如「句式用 A 卡、尺度用 B 卡」）

## 📚 长篇作品工作区

- 每篇作品独立维护：逐章摘要 + 设定书 + 大纲
- 写新章节时自动注入上一章的状态，故事线稳稳的

## 🔒 隐私

所有产出、素材、风格卡都保存在本地，不上传任何服务器。

## 📁 目录结构

```
astrbot_plugin_write_sandbox/
├── main.py          # AstrBot 入口与工具注册
├── core.py          # 沙盒核心逻辑
├── prompts.py       # 提示词模板
├── metadata.yaml    # 插件元信息
├── PLAN.md          # 开发方案（需求变更先改这里）
├── outputs/         # 写作产出（运行时生成）
├── library/         # 素材库（放入待学习的 txt/md）
├── favorites/       # 收藏的高权重样本（运行时生成）
├── style_cards/     # 风格卡库（运行时生成）
└── constraints.json # 约束表（运行时生成，可手动编辑）
```
